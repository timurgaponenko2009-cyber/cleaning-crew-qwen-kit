## 1. Что случилось
Владелец посмотрел HUB в игре с твоими моделями и не принял его. Его слова: «где красивые модели как в референсах», «что за микробудка».

Что было не так:
1. **Масштаб.** `HB_SupplyStore` был 16×12 студов при высоте 6.2, то есть ростом с персонажа (см. `6_ОШИБКА_МАСШТАБА.png`, справа манекен 5.3). Станция улучшений 4 в высоту, шкаф 4.
2. **Коробки вместо формы.** У фургона, магазина и станций нет второго и третьего слоя формы и узнаваемого силуэта.
3. **Не тот стиль в HUB.** HUB был сделан изношенным и грязным («облачные» пятна, ржавчина, оранжевый неон). В референсах владельца HUB — новая чистая дорогая фирменная компания: белый фургон с фирменной ливреей, современный магазин с полками и товаром, неоновое колесо наград, станция улучшений с большим экраном.

Поэтому всё в HUB переделываем заново: принятые раньше V1a, V1b, V2, H1, H2a, H3a, H3b тоже. Вердикты по каждой модели — в начале каждого файла.

## 2. Новый стиль (коротко)
- **HUB** — чисто, новое, дорого, тёплый солнечный вечер, сухо. Палитра бренда: `BrandWhite` (основа), `BrandNavy` (рамы, вывески, низ ливреи), **`SafetyOrange` — главный акцент бригады** (ливрея, полосы, кнопки, кромки), графит `PowderCoat`/`Powder`, тёплое дерево `Cedar`, `LightConcrete`; свет — `LightEmit`, **`NeonOrange`**, `NeonWhite`. `BrandTeal` — только вода и чистота.
- **Миссии** — тёмный реализм, но красиво: износ только там, где трогают и где стирается (рёбра, углы, низ, ручки). Никаких облаков грязи по всей поверхности. Вещи бригады (инструменты тиров 2–3, ведро, тележка, дрон, коробка) — новые, белый и тёмно-синий с оранжевым акцентом.
- **Текст** геометрией не делаем. **Эмблема бренда — только через `emblem()`**, одинаковая везде. Под название оставляй пустую панель `SignBand`: текст напишет Claude.

## 3. Масштаб (главная причина брака)
1 = 1 студ. Персонаж 5.3. Дверь ≥ 4×7.5 (входная в магазин и штаб — 8×9). Этаж 12–14. Проход ≥ 6. Здание ≥ 3 ростов, станция ≥ 1.7 роста.
- **В каждом `@asset`, у которого в ТЗ есть габарит, пиши `size=(X, Y, Z)`.** Отклонение больше 5 % по любой оси — CHECK ERROR. Габарит считается по всем деталям, поэтому выступающие части тоже должны в него укладываться.
- В `closeups.png` рядом с каждой моделью от 3 студов стоит белый манекен 5.3. Перед сдачей смотри: сколько ростов в модели?
- Отчёт сам предупреждает: здание ниже 11, фургон короче 15, дверь ниже 7.5. **Пакет с таким WARN не принимается.**

## 4. Что есть в cc_kit сейчас (обнови библиотеку до `5_cc_kit.py`)
**Новое в run и Builder:**
- `run("R1", wear="clean")` — износ всего пакета. `clean` для всех `HB_*`, `used` для лёгкого износа, `worn` (по умолчанию) для миссий. Грязь теперь — подтёки сверху вниз, а не облака.
- `B.add(..., wear=0..1)` — износ одной детали. 0 — новое, 1 — старое. Тиры 2–3 и вещи бригады — 0–0.15, тир 1 — 0.7–1, мебель офиса — 0.4–0.7, `_Clean` — не больше 0.2.
- `B.add(..., flat=True)` — гранёный шейдинг: листва-кристаллы, горы, ярусы ели.
- `B.add(..., tile=0.5)` — свой масштаб текстуры детали (мелкие инструменты 0.5–1).
- `B.add(..., anim="slide", axis="X", dist=3.8)`, `anim="swing", angle=100`, `period=`, `phase=` — ход и фаза анимации (пишутся в `anim.json`).
- `B.mark("PromptCounter", (x, y, z), dir=(0, -1, 0))` — точка для кода: подсказка, экран, центр колеса, полка, источник пара (`markers.json`). **Ставь метки везде, где ТЗ их называет.**
- `B.light("Glow", "point"|"spot"|"surface", pos, dir, color=(r,g,b), range, brightness, angle)` — источник света Roblox (`lights.json`).

**Новые функции:**
- `@asset(name, size=(X, Y, Z))` — контроль габарита.
- `emblem(c, d, depth=0.08, face="-Y")` возвращает `{"badge", "drop", "bubble", "spark"}`: подложка-круг, капля, кольцо-пузырь, блик. Материалы: badge `BrandNavy` или `BrandWhite`, drop `BrandTeal` (вода), bubble `SafetyOrange` или `BrandWhite`, spark `NeonWhite`.
- `rrect(w, h, r, n=6, cx=0, cz=0)` — скруглённый контур для `prism`.
- `arcpts(cx, cz, r, a0, a1, n)` — точки дуги: арки, волны ливреи, секторы.
- `soften(bm, levels)` — подушки, мешки, тряпки, верёвки.
- `displace(bm, amp, scale, seed)` — мятая ткань, бумага, плёнка.
- `mirror_x(bm)` — левая перчатка из правой.
- Префикс `FH_` (Семейный дом), до 60 объектов на файл.
