# V5 — Инструменты уборки (`TK_`): в руках от первого лица и в магазине

Игра ищет модели инструментов по имени **`TK_<модель>`** — имена ниже менять нельзя. Модель видна **крупно в руках** и в витрине магазина, поэтому детализация выше обычной: до 5 000 треуг., фаски везде, мелкие надписи-рельефы, следы износа.
**Pivot — точка хвата** (где ладонь держит ручку), ручка/корпус вдоль оси **+Z** вверх, рабочая часть (головка, сопло) — вниз или вперёд по −Y.

| Ассет | Габарит | Что обязательно |
|---|---|---|
| `TK_SprayBottle` | 0.6×0.4×1.1 | распылитель: бутылка с полупрозрачным `Plastic`, курок, сопло с поворотной головкой, трубка внутри, этикетка-рамка |
| `TK_Cloth` | 1×0.8×0.15 | сложенная микрофибра со складками (несколько слоёв `Fabric`, Rng-смещения), обтрёпанный край |
| `TK_Sponge` | 0.8×0.5×0.4 | губка: мягкий слой + абразивный слой другого цвета, поры (`specks` не нужен — фаски и вмятины) |
| `TK_Brush` | 0.7×0.4×1.2 | щётка с ручкой: колодка, ряды щетины (пучки — тонкие цилиндры циклом), ручка с резиновой вставкой |
| `TK_BrushSoft` | 0.7×0.4×1.2 | мягкая щётка: светлая длинная щетина, деревянная колодка |
| `TK_Squeegee` | 1.4×0.3×1.6 | стеклосгон: ручка, рамка, резиновое лезвие `Rubber`, фиксатор |
| `TK_Mop` | 1.4×0.9×5.6 | швабра: телескопическая ручка с фиксатором, держатель, плоская насадка-моп с бахромой (ряды `sweep`) |
| `TK_Bucket` | 1.4×1.4×1.4 | ведро для швабры на колёсах с отжимом-прессом, рукоять отжима, вода внутри (плоскость `Glass` на 2/3 высоты) |
| `TK_Vacuum` | 1.2×1.2×2.8 | промышленный пылесос: бак, колёса, шланг (`sweep` с гофрой — кольца `torus`), трубка, щётка, кнопка, кабель |
| `TK_PressureWasher` | 1.6×1.2×2.4 | минимойка: корпус на колёсах, барабан шланга, пистолет-распылитель |
| `TK_ChemBottle` | 0.5×0.35×1.2 | бутылка химии с курком-дозатором, пустая этикетка-рамка (цвет задаёт игра — сам корпус `Plastic`) |
| `TK_ChemJug` | 0.9×0.6×1.2 | канистра химии с ручкой и крышкой, пустая этикетка-рамка |
| `TK_ExtensionCord` | 1.2×1.2×0.6 | катушка удлинителя с намотанным кабелем, розетки |
| `TK_Trolley` | 2.4×4×3.4 | тележка уборщика бригады (вариант `OF_JanitorCart` в оранжевом исполнении бригады) |
| `TK_ToolBox` | 1.8×0.9×1 | ящик для инструмента: ручка, защёлки, лоток внутри |
