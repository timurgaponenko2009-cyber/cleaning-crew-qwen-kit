# V11 — Что ещё видно в игре: ведро миссии, доставка, станции HUB, растения (`CC_`, `HB_`)

Эти модели игра уже использует (сейчас — временные из деталей или старые), имена **точно как ниже**: код ищет их по имени. Стиль Dark Realism (дождливый вечер, рабочий износ, оранжевый акцент бригады `SafetyOrange`, без надписей и логотипов текстом). Износ — только материалом и геометрией. Pivot — центр низа, если не сказано иначе.

## Миссия и доставка
| Ассет | Габарит | Что обязательно |
|---|---|---|
| `CC_MopBucket` | 1.6×1.2×1.5 | ведро бригады на колёсах с прессом-отжимом. **Отдельные детали с точными именами:** `Water` — плоский цилиндр на уровне воды внутри (Material `Glass`, без коллизии; игра двигает его по высоте и красит), `WringerHandle` — рычаг отжима, **pivot в шарнире** (игра поворачивает его вниз на ~38° по локальной X). Корпус, внутренняя ёмкость, слив-пробка, метки уровня (рельеф), колёсики, корзина отжима |
| `CrewDrone` | 3×3×0.8 | дрон доставки бригады: квадрокоптер, 4 винта (`Rotor1..4` отдельно, pivot в оси — игра крутит), захват для коробки снизу, огни `LightEmit` |
| `CrewPackage` | 1.6×1.2×1 | коробка поставки: картон, лента, ручки-прорези, ремень-стяжка, пустая рамка под наклейку |

## Станции HUB
| Ассет | Габарит | Что обязательно |
|---|---|---|
| `HB_MissionBoard` | 3×1.2×4 | терминал выбора заказа у парковки фургонов: стойка, тёмный экран-панель (`Screen` отдельной деталью — на него игра рисует UI), козырёк от дождя, кабель-канал, подсветка-кант `NeonOrange` |
| `HB_UpgradeStation` | 6×4×4 | станция улучшений инструментов: верстак, тиски, стенд инструментов, экран-терминал (`Screen` отдельно), лампа над верстаком, ящики |
| `HB_EquipmentLocker` | 4×1.6×4 | шкаф со снаряжением для обучения: две створки **отдельно** (`DoorL`, `DoorR`, pivot в петлях — игра их открывает), полки внутри, крючки, вентиляционные прорези |
| `HB_LuckyWheel` | 8×2×9 | колесо наград в стиле бригады: стойка-основание, колесо (`Wheel` отдельно, pivot в оси — игра крутит) с 8 секторами разных цветов, указатель сверху, подсветка-лампы по ободу (`LightEmit`) |
| `HB_CrewPad` | 9×9×0.4 | площадка посадки бригады у фургона: круглая плита с оранжевым кольцом-разметкой, утопленные светильники по кругу, дренажная решётка |
| `HB_DeliveryPad` | 6×6×0.3 | площадка приземления дрона: квадрат с разметкой-крестом, угловые огни, решётка-сток |

## Растения HUB (дождливый вечер, не мультяшные)
| Ассет | Габарит | Что обязательно |
|---|---|---|
| `HB_TreeOak` | 14×14×18 | лиственное дерево: ствол с корой (`WornWood`), ветви `sweep`, крона из нескольких групп листвы (не один шар), мокрый вид |
| `HB_TreePine` | 9×9×22 | ель: ярусы веток вниз, ствол, тёмная хвоя |
| `HB_TreeBare` | 10×10×14 | голое/полузасохшее дерево для заброшенных зон |
| `HB_Bush` | 4×4×2.5 | куст из нескольких сфер-групп листвы с неровным силуэтом |
| `HB_GrassTuft` | 1.5×1.5×1 | пучок травы (плоские лезвия-полосы), для расстановки сотнями — до 300 треуг. |

Бюджет: деревья до 6 000 треуг., остальное до 4 000. Проверка: `CHECK` без WARN по pivot (кроме деталей, где pivot задан в оси), подвижные детали — отдельными объектами с указанными именами.
