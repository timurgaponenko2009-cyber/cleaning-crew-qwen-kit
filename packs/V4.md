# V4 — Мусор и мелочь для уборки (`TR_`)

Предметы, которые игрок подбирает в мешок или несёт к урне. Лежат на полу россыпью, видны с 2–6 studs — нужна читаемая форма и мелкие детали. 200–800 треуг., pivot — центр низа, лежат естественно (не идеально ровно).

| Ассет | Габарит | Что обязательно |
|---|---|---|
| `TR_Cups` | 1×1×0.6 | 2–3 бумажных стаканчика с крышками, один смят, один лежит на боку |
| `TR_Bottles` | 1.2×0.8×0.5 | 2 пластиковые бутылки (lathe), одна смята, крышка рядом |
| `TR_Cans` | 1×0.8×0.5 | 3 банки, одна раздавлена (сплюснутый цилиндр) |
| `TR_PaperBall` | 0.5×0.5×0.45 | смятый лист (ball с Rng-вмятинами из боксов) |
| `TR_PizzaBox` | 1.6×1.6×0.3 | коробка пиццы, крышка приоткрыта, жирное пятно |
| `TR_FoodWrap` | 0.8×0.6×0.15 | обёртки от еды, пакет из фастфуда |
| `TR_BagGeneral` | 1.4×1.2×1.6 | чёрный мусорный мешок, завязка, складки |
| `TR_BagBio` | 1.4×1.2×1.6 | красный мешок биоотходов `WarnRed`, пломба-хомут, знак-рамка |
| `TR_Cardboard` | 2×1.4×0.4 | сложенный картон, перевязанный бечёвкой (Recycling) |
| `TR_BrokenGlass` | 1.4×1.2×0.3 | осколки стекла (8–12 клиньев prism, Rng), острые края |
| `TR_Rag` | 1×0.8×0.15 | грязная тряпка складками |
| `TR_CigButts` | 0.6×0.6×0.1 | окурки кучкой (5–8 цилиндров) |

После приёмки Claude переключит мусор миссий на эти модели.
